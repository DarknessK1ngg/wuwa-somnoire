# Somnoire Dossier

Wuthering Waves under VS Battles rules: the Somnoire dream hierarchy, with every line quoted from the game in the original Chinese.

## Run locally

```
npm install
npm run dev
```

## Publish on GitHub Pages

1. Push this folder to a GitHub repository (branch `main`).
2. In the repository: Settings → Pages → Source: **GitHub Actions**.
3. Every push to `main` builds and publishes the site to `https://<user>.github.io/<repo>/`.

Built with Vite, React, React Three Fiber, ShaderGradient and Motion.
Fan analysis. Not affiliated with Kuro Games.
